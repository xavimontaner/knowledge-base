# Linux 002 – What is Linux?

## Overview

Linux is **not** a complete operating system by itself.

Technically, Linux is a **kernel**: the core component responsible for managing hardware resources and allowing software to communicate with the computer.

---

## GNU and Linux

During the 1980s, Richard Stallman started the GNU Project to build a free Unix-like operating system.

GNU developed almost everything required for an operating system:

- Bash
- GCC
- Core utilities
- Libraries
- Development tools

However, GNU lacked a working kernel.

In 1991, Linus Torvalds created the Linux kernel.

Combining GNU's tools with the Linux kernel resulted in a complete operating system, commonly referred to as **GNU/Linux**.

---

## Important Distinction

- **Unix** is a complete operating system.
- **Linux** is a kernel.
- Linux distributions (Ubuntu, Debian, Fedora, Arch...) combine the Linux kernel with many additional tools and applications.

---

## Key Takeaways

- Linux was created by Linus Torvalds in 1991.
- Linux is a kernel, not a complete operating system.
- GNU provided most user-space tools.
- GNU + Linux = GNU/Linux.
