# Linux 001 – What is Unix?

## Overview

Unix is one of the most influential operating systems ever created. Although Linux does **not** use Unix's source code, it was heavily inspired by Unix's design philosophy and architecture.

Understanding Unix helps explain why Linux works the way it does today.

---

## A Brief History

- **1969** – Ken Thompson and Dennis Ritchie create Unix at Bell Labs.
- Unix is later rewritten in the **C programming language**, making it portable across different hardware architectures.
- Unix becomes widely adopted by universities and companies, influencing generations of operating systems.

---

## Why C Was Revolutionary

Originally, Unix was written in Assembly.

Since Assembly is specific to a processor architecture, moving Unix to another machine required rewriting large parts of the operating system.

By rewriting Unix in **C**, developers could compile the same source code for different processors instead of rewriting it entirely.

This portability was one of the key reasons for Unix's success.

---

## Key Takeaways

- Unix introduced many ideas that modern operating systems still use.
- Writing Unix in C made it portable.
- Linux is inspired by Unix's design, **not** by its source code.
